# Master Messenger

Рабочий Telegram-подобный веб-клиент с локальным хранением сообщений.

## Что реализовано

- Список диалогов и экран переписки.
- Поиск по чатам и последним сообщениям.
- Отправка сообщений.
- Автоответ для демонстрации входящих сообщений.
- Сохранение истории чатов в `localStorage`.
- Переключение светлой/тёмной темы.

## Запуск

```bash
python3 -m http.server 4173
```

После этого откройте <http://localhost:4173>.
